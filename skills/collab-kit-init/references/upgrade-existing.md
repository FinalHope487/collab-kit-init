# 升級舊版 kit：要改掉的舊措辭

步驟 1b 用。專案已經有舊版規則檔章節時逐條檢查。已存在的章節不覆蓋，
但下面這些會與新加的章節直接打架，逐條改掉。「換成」指 `assets/claude-md-rules.md`
（推送政策見 `assets/push-policy-*.md`）目前版本的對應文字。

## 用詞

先用 `grep -nE '使[用]者|受[託]方|主[ ]agent|CLAUDE\.md|AGENTS\.md'` 找出規則檔裡的舊用詞，逐處改。

| 舊 | 改成 |
|---|---|
| 指人類的「使[用]者」與 user 第一人稱「我」（例「不要問我，自己做」「讓我決定」「待我裁示」） | 「user」（「不要問 user，自己做」「讓 user 決定」「待 user 裁示」）；意思不變 |
| 「受[託]方」「主[ ]agent」 | 被委派的是「subagent」，委派的人是「你」 |
| 規則文字裡寫死的 `CLAUDE.md`／`AGENTS.md` | 「規則檔」 |
| 「使[用]者層」「使[用]者可見行為」 | 「user 層」「user 可見行為」 |
| 開頭沒有語言句，或舊句「預設用使[用]者的語言回答」 | 規則檔最前面一句「用規則檔所寫的主要語言回答問題，不是 user 的語言。」，刪掉舊句 |

## 留痕與收尾

| 位置 | 舊 | 改成 |
|---|---|---|
| 推送政策 | 與安裝時選的那一版不同（「絕不 push `main`」與「直接推 `main`」並存或選錯） | 整段換成選定那一版 `assets/push-policy-*.md` 的 `CLOSING`；〈決策分級〉的 `TIER_MEDIUM`、`TIER_NOTE` 同步換 |
| 收尾第 1 條 | 「更新狀態，並改掉測試數」 | 覆寫〈基線〉：含 commit SHA 與本輪實跑的測試數，沒跑的層寫「未跑」 |
| 「只推綠的東西」 | 「push 前跑完全部項目」 | push 前跑必要之測試，全套由 CI 兜底；只動文件的免跑 |
| 獨占工作目錄 | 寫死某個專案的埠號清單 | 通用句，埠清單放安裝時填的 `--service-ports` |
| `QUESTIONS.md`「每一輪都要被碰過」 | 同時寫在〈什麼算一題〉與收尾 | 只留在收尾第 2 條 |

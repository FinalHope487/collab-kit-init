# Roadmap

只有四節：〈硬約束〉〈基線〉〈待辦項目〉〈範圍〉。
決策不放這裡——一條決策一個檔，放 `docs/decisions/`。

新想法寫進〈待辦項目〉並標記，不當場插隊打斷目前任務。
每輪結束前覆寫〈基線〉。

## 標記說明

- `[now]` — 阻塞當前任務
- `[next]` — 目前模組穩定後就做
- `[blocked]` — 等別的事先完成，或等 `QUESTIONS.md` 的某一題
- `[later]` — 現在做屬於過早設計，等需求明確再說
- `[parked]` — 使用者裁示不排程

這五個以外的標籤不准用。

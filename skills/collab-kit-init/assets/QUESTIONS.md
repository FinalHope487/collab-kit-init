# 待決問題

**一題 ＝ 你看一次、答一次就結案的問題。** 這裡只寫問題本身與它為什麼存在，
不寫選項——選項在我用 AskUserQuestion 問你的當下才給。

答完的題我當場刪除，內容依性質搬進 `docs/decisions/` 或 `SOP/` 對應的症狀分類檔。
你答得不清楚時，我刪掉原題，把還混淆的那一點寫成新的一題。

規則見 `CLAUDE.md`〈提問機制〉〈什麼算一題〉。**每一輪都要碰這個檔**：
有題就開題，沒題就清到只剩本段以上的內容。

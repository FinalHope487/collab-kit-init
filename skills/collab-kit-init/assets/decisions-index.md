# 已拍板的決策

推翻這裡的任何一條屬高風險，要先問使用者。不要重新論證已經論證過的事。

一條決策一個檔，檔名 `YYYY-MM-DD-<slug>.md`，首行 `# YYYY-MM-DD · 標題`。
每個檔 ≤30 行，必須寫得出三件事：

- **決策**：定了什麼
- **依據**：為什麼——指得出來源，既有慣例在哪個檔哪一行
- **反悔成本**：改回來要動哪幾個檔，既有資料會不會受影響

被測試釘住的加一行 `**釘住**：<測試名>`。
量測表與除錯過程不寫進決策檔，放 `evidence/<同名>.md`。

不綁日期的不變量型設計理由放 `topics/<主題>.md`，不套日期格式。
